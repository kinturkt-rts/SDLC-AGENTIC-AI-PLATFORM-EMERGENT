Simple Notes API — developer-agent smoke test

Purpose:
- Prove the SDLC pipeline can produce a runnable FastAPI app with no database and no external services.

MVP (in-memory only):
- GET /health → {"status": "ok"}
- GET /notes → list all notes (JSON array)
- POST /notes → create a note from body {"title": str, "body": str}; return created note with id
- GET /notes/{id} → one note or 404

Rules:
- Python 3.12 + FastAPI + Pydantic v2
- Store notes in memory (Python list or dict) — no Postgres, no MongoDB, no Redis
- No auth, no Azure, no AWS SDK, no LLM calls in the app
- Include pytest tests for /health and POST+GET /notes
- README with: venv, pip install, uvicorn app.main:app --reload

Out of scope:
- Database, migrations, Docker, frontend UI, Jira, GitLab

Success:
- pytest passes
- Service starts on port 8000 and /docs shows the three note endpoints
