# Team Notice Board API\n\nA FastAPI application for managing team announcements, reminders, and wins with Streamlit dashboard.\n\n## Features\n\n- **Public API**: Read active notices and categories (no auth required)\n- **Protected Management**: Create, update, and archive notices with API key\n- **Streamlit Dashboard**: Web interface for browsing and managing notices\n- **Filtering & Search**: Active-only filter, category filter, text search\n- **PostgreSQL Backend**: Persistent storage with RDS support\n\n## Quick Start\n\n### Prerequisites\n\n- Python 3.12+\n- PostgreSQL database (local or RDS)\n- Git Bash or PowerShell (Windows)\n\n### Setup\n\n1. **Navigate to app directory**\n   ```bash\n   cd target-apps/gitlab-pipeline-smoke\n   ```\n\n2. **Create virtual environment**\n   ```bash\n   # PowerShell\n   python -m venv .venv\n   .venv\\Scripts\\Activate.ps1\n   \n   # Git Bash\n   python -m venv .venv\n   source .venv/bin/activate\n   ```\n\n3. **Install dependencies**\n   ```bash\n   pip install -r requirements.txt\n   ```\n\n4. **Configure environment**\n   ```bash\n   cp .env.example .env\n   ```\n   \n   Edit `.env` and set:\n   - `DATABASE_URL=postgresql+psycopg://username:password@host:5432/database?sslmode=require`\n   - `API_KEY=your-secret-api-key-here`\n   \n   ⚠️ **Important**: Every line needs the variable name — paste `DATABASE_URL=postgresql+psycopg://...`, not a bare URL.\n\n5. **Run database migrations** (if using RDS)\n   ```bash\n   # Apply SQL files to RDS (from repo root)\n   python scripts/apply_sql_to_rds.py target-apps/gitlab-pipeline-smoke/db/sql/\n   ```\n\n### Running the Application\n\n#### Terminal 1: API Server\n```bash\ncd target-apps/gitlab-pipeline-smoke\n.venv\\Scripts\\Activate.ps1  # Windows\n# source .venv/bin/activate  # Linux/Mac\nuvicorn app.main:app --reload --port 8000 --reload-dir app --reload-dir schemas\n```\n\n#### Terminal 2: Streamlit Dashboard\n```bash\ncd target-apps/gitlab-pipeline-smoke\n.venv\\Scripts\\Activate.ps1  # Windows\n# source .venv/bin/activate  # Linux/Mac\ncd ui\nstreamlit run streamlit_app.py --server.port 8501\n```\n\n### Access Points\n\n- **API Documentation**: http://localhost:8000/docs\n- **API Health Check**: http://localhost:8000/health\n- **Streamlit Dashboard**: http://localhost:8501\n\n## API Usage\n\n### Authentication\n\nWrite operations require API key authentication:\n\n```bash\n# In Swagger UI: Click \"Authorize\" and enter your API key\n# In curl: Add header\ncurl -H \"X-API-Key: your-api-key\" ...\n```\n\n### Example Requests\n\n```bash\n# Get health status\ncurl http://localhost:8000/health\n\n# List categories (public)\ncurl http://localhost:8000/api/v1/categories/\n\n# List active notices (public)\ncurl http://localhost:8000/api/v1/notices/?active_only=true\n\n# Search notices (public)\ncurl \"http://localhost:8000/api/v1/notices/?q=engineering&limit=10\"\n\n# Create category (requires API key)\ncurl -X POST http://localhost:8000/api/v1/categories/ \\\n  -H \"Content-Type: application/json\" \\\n  -H \"X-API-Key: your-api-key\" \\\n  -d '{\"name\": \"Engineering\", \"description\": \"Technical updates\"}'\n\n# Create notice (requires API key)\ncurl -X POST http://localhost:8000/api/v1/notices/ \\\n  -H \"Content-Type: application/json\" \\\n  -H \"X-API-Key: your-api-key\" \\\n  -d '{\n    \"title\": \"System Maintenance\",\n    \"body\": \"Scheduled maintenance window this weekend.\",\n    \"author_name\": \"DevOps Team\",\n    \"category_id\": \"category-uuid-here\",\n    \"starts_at\": \"2024-01-15T20:00:00Z\",\n    \"ends_at\": \"2024-01-16T06:00:00Z\"\n  }'\n\n# Archive notice (requires API key)\ncurl -X POST http://localhost:8000/api/v1/notices/{notice-id}/archive \\\n  -H \"X-API-Key: your-api-key\"\n```\n\n## Seed installed\n.venv\\Scripts\\Activate.ps1\npip install -r requirements.txt\n```\n\n**Database connection failed**\n- Verify `DATABASE_URL` in `.env` is correct\n- Check network connectivity to RDS instance\n- Ensure schema `gitlab_pipeline_smoke` exists\n- Test connection: `curl http://localhost:8000/health`\n\n**API key authentication failed (401)**\n- Set `API_KEY` in `.env` file\n- Use `X-API-Key` header in requests\n- Check Swagger UI authorization\n\n**Streamlit can't reach API**\n- Ensure FastAPI is running on port 8000\n- Check `API_BASE_URL` in `.env` (default: `http://localhost:8000`)\n- Verify both terminals are using the same virtual environment\n\n### RDS Smoke Test\n\n```bash\n# Test direct database connection\npsql
