Build a medium Weekly Pulse Check for team health check-ins.

Problem:
- Managers ask “how is the week going?” in chat and answers disappear.
- Teams want a short weekly pulse (mood + one win + one blocker) with a simple history view.
- A lightweight UI is required so people do not live in Swagger.

Who uses it:
- Team members submit a weekly pulse (week start date, mood 1–5, win text, optional blocker).
- Managers browse team pulses and generate a short AI summary for a chosen week.
- v1 uses a shared API key from the app (no personal login table yet). Health checks stay open for ops.

MVP features:
- Submit a pulse entry: member name, week_start (Monday), mood (1–5), win, optional blocker.
- Browse pulse history with filters by person and week/date range.
- Generate an AI week summary from pulses in that week (team mood trend, wins, open blockers).
- List past weekly summaries.
- A simple Streamlit UI with tabs to submit pulses, view history, and generate/view summaries.
- Seed a few sample pulses for the current week and one prior summary so demos work immediately.

Business rules:
- One pulse per member per week_start (upsert or reject duplicates clearly).
- Mood must be an integer from 1 to 5.
- Summaries must only use real pulse entries in the selected week — never invent wins or blockers.
- If there are no pulses in range, say clearly that there is no data and how to add some.
- Requests without a valid API key should be rejected (except health).

Must have for v1:
- Persisted data (not in-memory only).
- Backend API plus Streamlit UI that talks to the API over HTTP.
- AI summary generation that can be demoed (mockable in tests).

Nice to have (later):
- Slack bot, anonymous mode, personal logins / SSO, trend charts over quarters.

Constraints:
- Internal use only; manual entry in v1.
- Keep secrets out of source code and out of generated summaries.

Success:
- A teammate submits pulses in the UI; a manager picks a week, generates a Markdown summary, and can reopen past summaries.
- Filtering history by person or week shows the right entries.
