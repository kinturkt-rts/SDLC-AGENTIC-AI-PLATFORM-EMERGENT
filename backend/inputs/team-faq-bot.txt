Build a lightweight team FAQ chatbot (not full document RAG).

Problem:
- New hires ask the same questions in Slack about PTO, laptops, and deploy process.
- Answers live in a scattered wiki; nobody updates them.

MVP:
- Admin uploads a plain-text FAQ file (Q&A pairs or bullet topics).
- User asks a question in chat; bot answers from that FAQ only.
- If no match, reply "not in FAQ" — no guessing.

Must have:
- One FAQ collection per team; replace file to refresh content.
- Chat UI + REST POST /ask.
- Store questions asked (for gaps list), not full chat transcripts with PII.

Constraints:
- Single team scope in MVP; no cross-team FAQ mixing.
- FAQ files under 50k chars for v1.
- Bedrock for answer generation; cite FAQ section in response.

Success:
- Common onboarding questions answered correctly without human ping.
